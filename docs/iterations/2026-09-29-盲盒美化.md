# 2026-09-29 盲盒美化

把日历上的「问号方块」改成自己画的礼盒，并补上今天标记。

## 盒子

- 未揭晓：格子本身是淡薰衣草包装盒，浅金点 + 十字缎带。
- 已揭开心日：浅米金包装卡，无缎带。
- 已揭危险日：浅藕粉包装卡，无缎带。
- 第一次得分：全屏开盒动画仍然是掀盖礼盒。

礼盒是自己画的包装卡片（格子本身就是盒子），没有用现成贴图，格子里不再放礼盒图标。

## 格子怎么排（避免眼花）

- 格子间距加大；未揭晓用淡薰衣草包装纸 + 浅金点；黄色十字封条交在右上黄金分割点（约 61.8% × 38.2%）。
- 格子里只留：日期、开心日中间大号倍率、危险日中间大号门槛、一行状态字（待开 / 还没到 / 得豆或已加/门槛）。
- 星期只在表头。
- 开心日浅米金包装，危险日浅藕粉包装；加满门槛变浅绿，凌晨未过关略加深红。
